## 4. 执行架构(与既有纪律逐字一致)

- 我构建 IBKR 实盘执行器:**五层安全照 OKX/QMT 移植**(账户钉扎 fail-closed →
  订单级上限 → 对账 RECONCILE 旗标 → 长多/单票/gross 钳制 → 回撤 HALT);
  dry-run 默认。
- **send 开关在用户**:执行器生成订单清单 → 用户审阅 → 用户运行 send。我不执行
  任何真实交易,不接触券商凭据(凭据只活在用户配置的 Gateway 里,与 IBC 同款)。
- 现有 IB Gateway 自动化(IBC 登录/自愈/每日重启)复用;实盘账户与纸面账户隔离,
  执行器钉扎实盘账户 ID,不匹配即拒发。

## 5. 测量协议(TCA)

每笔真实订单记录:决策价(信号 bar 收盘)、到达价(下单时刻中间价)、成交价、
到达时点差、成交延迟。月度 TCA 报告(cli tca 现成)。

**预注册判据(90 个日历日后)**:
- 中位滑点 ≤ 10bp/边 **且** 执行链零安全事故(零对账旗标、零误单)→ 通道合格,
  记入 E62 档案,micro-live 继续;
- 中位滑点 > 25bp/边 → 通道不合格,停止并复盘;
- 之间 → 继续测量 90 天再判。
