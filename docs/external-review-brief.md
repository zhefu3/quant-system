# qtrade 项目全景报告(供外部评审)

> 目的:请评审者(你)以怀疑者视角审视这个系统——指出方法论漏洞、过拟合风险、
> 执行盲区、以及"以我们的约束条件还能做什么"。最有价值的反馈是"你们错在哪/
> 你们看不见什么",而不是夸奖。
> 敏感信息(券商、凭据、真实资金数额)已脱敏;所有收益数字来自纸面模拟或回测。
> 快照日期:2026-07-26。

## 一、项目是什么

个人量化研究/交易系统,运行在一台 macOS 上,数据全部免费源,月度现金成本
~$1(LLM API)。九本**纸面账**(paper books)每小时并行运行,覆盖五个资产类
(crypto 永续 / 国内商品期货 / 美国期货 / 美股 ETF / A股+可转债)和四种信号源
(机械规则 / 梯度提升 ML / LLM 委员会 / 估值轮动)。执行层:OKX 就绪(未开)、
IBKR 网关自动化运行(只读)、国内 QMT 执行器已预建(等券商权限)。

核心特征不是任何单一策略,而是**预注册纪律**:67 个编号实验(E1–E67),18 个
正式判决,每个实验在跑回测**之前**冻结假设、参数、成本模型、通过门槛和判决
分支;失败照记,关闭的方向写明重开条件。研究日志是权威记录,所有判断必须
引用原文。

## 二、方法论(请重点攻击这一节)

1. **预注册**:门槛(如"净 Sharpe>0.8 且两半段皆正")在见到结果前写死;判决
   分支(过/边缘/不过分别怎么办)预先承诺。目的:堵住"先看结果再挪门柱"。
2. **成本先行**:每个回测用冻结的费率+滑点模型(A股含印花税/过户费,转债
   万1,crypto taker 5bp+资金费),敏感性至少测两档滑点。
3. **样本外结构**:时间上前后半段都要为正才过门槛;部分实验留纯净段
   (如 crypto 2019–22)只做最终确认。
4. **前瞻记录高于回测**:观察账本(没过门槛或无法回测的)只积累 forward
   record,被制度性锁在组合层之外,不得作为资金配置证据。
5. **月度再验证自动化**:每月 1 号对所有验证过的策略用最新数据重跑审计,
   历史存档;衰减状态机(连续 2 周 warning 触发复审)。
6. **统计工具**:bootstrap 置信区间、回撤置换检验、平行 A/B 统计裁决器、
   "运气检验"(纸面账 vs 回测期望的偏离)。
7. **诚实短板**:67 个实验存在家族性多重检验问题——我们全量记录所有尝试
   (含失败)来缓解,但没有做正式的多重检验校正(如 White's Reality Check /
   SPA)。这是已知开放问题,欢迎批评。

## 三、九本账本明细

### 1. crypto_core(旗舰,七年验证 ★★★)
- 1h 频,10 个主流币 USDT 永续(BTC/ETH/SOL/XRP/DOGE/ADA/AVAX/DOT/LINK/LTC)
- 信号:50/50 复合——CTA 趋势(三横截面 96/288/720 小时)+ 布林带均值回归
  (窗口 96,入场 z=2,双向,720h 制度过滤);每条腿独立 VolTarget 40% 年化
  (168h 窗口)

## 四、执行与真实化(A股部分请重点审)

纸面账不是"收盘价成交"的玩具,已做的真实化:

- **停牌/涨跌停判定**:每笔模拟成交对照当日 bar 判定 fill/suspended/
  limit_locked;涨停不能买、跌停不能卖;被锁定的调仓自动顺延重试,
  顺延成本(锁定期价格漂移)有专门报告(rebalance-report)
- **参照日纪律**:所有"今天能不能交易"的判定针对**池子自身的最大 bar 日期**
  (pool_ref_day),不用墙钟、不用基准指数——数据发布延迟和周末决策都会
  骗过那两者(这是三次彩排炸弹换来的设计)
- **冻结/影子语义**:不可成交的票冻结净腿但毛影子腿照常交易——信号衰减
  的测量不被执行摩擦污染
- **T+1**:QMT 执行器计划里,可卖量=持仓-当日买入;熔断只 HALT 不自动清仓
  (T+1 下恐慌性自动平仓不可逆,平仓是人的决定)
- **TCA 脚手架**:实盘路径记录到达价 vs 成交价,首笔真实成交起积累;
  E67 的复活判定权就交给实测滑点(≤5bp 复活,10bp 死),不靠拍脑袋
- **五层安全**(OKX 已实现,QMT 移植完毕):账户 UID 钉扎(fail-closed)→
  订单级上限(单笔名义额、订单数≤标的数)→ 交易所对账(венue 状态必须
  落在上次 pre 与 target 之间,违规挂 RECONCILE 旗标禁发单)→ 权重/gross
  钳制 → 回撤熔断

## 五、基础设施与可观测性

- 每小时 launchd 循环跑九本账;硬超时逐层(墙钟 900s 为最后防线,每层
  请求各有有界失败);价格非有限不成交
- 主动告警:health 检查 → macOS 推送(去重、24h 提醒、恢复通知)
- **监控的监控**:多源对账(BTC/ETH 双所比对、A股 tushare vs akshare 按
  上海时区对齐、双基准一致即通过);任何交叉检查连续 3 天没完成过一次
  比对,自己升级为 WARN(教训:曾有一条检查从部署起就静默失败)
- **异地死人开关**:每日备份推送私有仓即心跳,GitHub Actions 异地监视,
  >36h 无推送自动开 issue 发邮件——单机死亡也有人报丧
- 时间戳约定集中一处(timeconv),扫描测试禁止包内裸 .date()——十天内
  三起事故同属时区/日期缺陷类之后的结构性预防
- 前瞻记录(权益/成交/决策/执行日志=不可再生证据)每日异地备份;
  恢复演练通过
- 转债条款事件 PIT 数据集自 07-21 起每日自采(强赎状态跃迁+下修生效),
  这是在**自己制造**E65 的重开条件(公告日历史数据买不到/不可信)
- 测试套件 158 项,含事故哨兵测试(如"超时异常必须穿透宽 except")

## 六、失败墓地(与成功同等重要)

全部预注册后判死,重开条件写入日志:股票截面动量(3个宇宙)、A股价格因子、
A股线性基本面因子、crypto 基差 carry、参数集成、组合级 vol target、分套
节流、扩池 16 币、低 beta 倾斜、换手缓冲、商品 carry、商品截面动量、真实
ETF 防守、461 因子公共库(零增量)、宇宙扩容 300→800(月频零增量)。

三个最有信息量的近期判决:
- **E65 转债下修博弈**:过了后段门槛(+10.7%/Sharpe 1.31)但归因证伪——
  下修事件仅贡献 16%,84% 是深折价 beta,与已有转债账本收益相关 0.77 →
  不建账。教训:过门槛≠新信息源,归因检验应成为标配
- **E66 隐波仓位标定**:前瞻性是真的(2022H1 确实提前降杠杆)但方差风险
  溢价税更贵,ΔSharpe -0.22 → 关闭。诚实先验(赢面只在崩盘预判)完全兑现
- **E67 低溢价周频轮动**:信号真实但 25% 周换手死在可复制费率;判决分支
  预先绑定实测滑点(QMT TCA ≤5bp 复活)——把"策略生死"交给可测量的量

## 七、事故史(工程教训,共八起,全部有 postmortem)

1. 无超时出网调用挂死循环(07-14)→ 全部出网调用硬超时
2. 接手数据仓库未读原抓取脚本约定,hfq 复权口径事故(07-15)→ 制度:
   先读原脚本;数据完整性闸门(复权悬崖熔断)
3. NaN 价格成交(07-15)→ 价格必须有限才可成交
4. 900s 墙钟异常被逐券 except 吞掉,裸挂 10 小时(07-16)→ 超时异常改为
   BaseException 派生;哨兵测试锁死
5. 网关僵尸:端口活着但 API 会话死了 8 小时,TCP 探针全程绿(07-21)→
   API 级功能探针(子进程+硬杀)
6. LLM 计费断供饿死整本账 10 小时(07-22)→ 优雅降级:断供冻结持仓,
   记账继续;委员会新鲜度独立告警
7. 跨源对账首次实弹就是自己的 bug:UTC .date() 在 CN 午夜时间戳上偏移
   一天,2.26pp 幻影背离(07-22)→ 上海时区对齐+双基准
8. IB 数据农场抖动 × 900s 硬杀 × 服务器端订阅泄漏三连环,32 小时断档,
   轻量级探针全程报 ok(07-23)→ 每层请求有界失败+失败即断连;
   教训:硬超时是最后防线不是第一防线
9. 交叉对账 crypto 腿从部署起静默失败 5 天(07-24)→ 暗窗升级机制;
   教训:能永远静默失败的监控不是监控

蒸馏出的原则:时区/日期约定是本仓库头号缺陷类;监控层自身需要被监控;
"被硬杀欠下的清理债"会变成远端状态泄漏。

## 八、已知弱点(我们自己的清单,看你能不能加长它)

1. **多重检验**:67 个实验没有正式的家族性校正,靠全量记录+OOS+前瞻缓解
2. **数据上限**:全免费源;日线/小时线,无分钟线无 L2;A股基本面 PIT 深度
   有限;期权链无
3. **前瞻记录太短**:最长的账本 17 天,所有纸面数字目前无统计意义
4. **单机**:计算是单点(告警已异地化,计算没有);家庭网络抖动直接打穿
   数据层(两天前刚发生)
5. **cb_double_low 的 2021 依赖**:已入档但账本还在跑,靠前瞻记录裁决
6. **A股 ML 的印花税地板**:解析性死局,除非信号升级
7. **仓位法原始**:逆波动率+固定 vol target,无 regime 模型,无相关性
   动态调整(跨账本相关矩阵只观测不行动)
8. **LLM 账本样本量**:日频决策,一年才 ~250 个样本点,统计功效很低
9. **执行真实化仍是模拟**:TCA 在第一笔真实成交前是空的;A股滑点假设
   (5-10bp)未经实测
10. **小资金物理**:最低佣金 ¥5 对 ¥2000 级订单是 25bp/边——费率谈判
    (免五)比任何 alpha 都重要,这很惭愧但很真实
