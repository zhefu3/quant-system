## 2. 你漏掉的漏洞(按你的要求,不重复原报告已列的十条)

1. **现货 K 线配永续成本**:crypto 回测读现货 bars、按永续费率计成本,现货/永续

   被高估"的判断互为表里。
3. **"验证年数"实为"数据可得年数"**:不止 crypto——美期货九品种共同窗口仅
   2.5 年(IBKR 历史上限,日志原文)。各账本证据标签将统一注明窗口的决定因素。
4. **90 天平行裁决的功效**:你打了 LLM 账本"一年 250 点功效低",但同样的炮口
   应对准我们 10-07 的主策略 vs 变体裁决——90 天日频 paired bootstrap 只能探测
