# E69-B 结果:五个情景一致——旗舰的历史数字与"过程运气"不可区分

**2026-07-29 · 340 个无 edge 世界 · GPT 评审 P0 清单的收官实验 · 判决:`ROBUST_TO_PROCESS_UNCERTAINTY`,且落在坏的那一档**

> 一句话:在没有任何真实 edge 的世界里,让一个"会搜索的研究过程"花掉和我们
> 七个月一样的预算,它例行公事地造出 ≥0.68 的赢家——旗舰的历史回测数字自此
> **不再构成独立证据**。这是整个评审循环里最重的一份结果,原样端上。

## 一、实验在问什么

E69-A 已经证明**冻结策略本身**不是纯运气(随机信号 1000 抽只有 3 次够到 0.68)。
但评审坚持拆出第二问:**产生这个策略的研究过程呢?** 七个月、61 个真实试验、
11 个家族、115 个记录在案的候选——如果把同样的搜索预算花在一个纯噪声世界里,
"赢家"会有多好?

设计(全部先于运行冻结):340 个块置换 null 世界;每个世界里模拟研究过程按预算
搜索(候选生成器复用台账家族结构,参数区间沿用 E69-A 冻结值);选择规则镜像
真实史的门槛式选择(两半皆正者取最优);三情景 = B1 固定图重放(82 个可重建候选,
最低搜索负担)/ B2 自适应代理三档(low/med/high,预算 115)/ B3 保守压力(预算
345 = 台账 ×3 上界)。

冻结判读:≥95 分位才算"搜索造不出",<80 即"与过程运气不可区分"。**五个情景
全部 <80,同档一致** → `ROBUST_TO_PROCESS_UNCERTAINTY`,档位是坏的:连只重放
82 个可确认候选的最低负担情景,都有 29% 的噪声世界"发现"了比旗舰更好的策略;
自适应政策下是过半。

## 五、机制注记(如实,均不改判决)

1. null 世界的块长(168h)大于策略最快腿(96h),块内短周期趋势结构按构造存活——
   null 赢家有真燃料(赢家家族分布:composite 104 / trend 74 居前)。这使 null
   偏严、赢家被垫高,即结论方向对历史数字**更不利也更保守**,无需辩解。
2. 两半门在 null 世界平均放行 20–39% 候选,门槛式选择被完整模拟,不是稻草人。
3. B3 中位赢家 0.77 显著低于 DSR 闭式的 E[max]=1.11(N=345)——实证低于理论,
   候选相关性压缩了有效试验数,与评审 correlated-null 的直觉一致。
4. 作者无法对自己盲化;缓解措施(政策参数全部取自台账结构与通用分位数,先于
   运行冻结并提交)已在预注册中披露。
