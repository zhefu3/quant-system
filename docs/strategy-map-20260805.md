# 外部策略地图:29 个家族的证据审判(2026-08-05)

**12 代理四路扫描 + 逐家族对抗打分(打分层直接在本地数据上复核) · 3 入选 / 6 暂存 / 20 判死**

> 方法先行:这不是"找灵感",是给"外部先验"这条证据腿正规补给。每个家族查一手
> 文献、查发表后衰减、对照我们的硬约束(免费数据/散户费率/A股无做空/已判死墓地)
> 打分;打分代理还被要求给出费后算术,**其中三个直接跑了我们自己的数据来复核
> 文献主张**——两个文献主张被自家数据推翻,一个数据封锁被实测解封。

## 一、三个改写结论的本地复核(这轮最值钱的产出)

1. **月末效应的美股腿被自家数据处死**:文献说"衰减最少的日历异象",打分代理用
   我们存的 SPY 数据分段复测:1993-2005 每日 +8.7bp(t=1.72)→ 2016-2026
   **+0.2bp(t=0.03)**——发表后二十年归零。文献综述没跟上,自家数据说了算。
2. **A股隔夜折价的先验被砍半但存活**:论文说 14bp/日,自家指数数据实测 2021-26
   是 **4-6bp/日**(且 2024-26 仍显著为负)。按实测先验,执行覆盖层价值
   +0.5-0.8%/年——用的是**实测数字而不是论文数字**立项。
3. **E56 的数据封锁被部分解封**:binance API 确认仍 451,但打分代理实测
   `data.binance.vision` 公开档案桶 HTTP 200,**资金费历史 2020 年起可回填**。
   已连夜回填 11 个永续合约的完整 funding 历史入库。

## 三、暂存(6 个,各带解锁条件)

- **清算级联后反转**:机制最硬(强平引擎结构性存在),落点=给布林 MR 加确认过滤器;等设计+自采 OI 成熟。
- **打板生态**(A股涨停):学术证据最硬的 A 股短周期 alpha(账户级数据文献),且我们有独家涨停池/龙虎榜 PIT 流;但文献同时警告散户排板=队尾逆向选择——**限定 live-forward 路径**:先用自有数据验证"封单强度→次日收益"的预测力,不预设可执行。
- **A股 PEAD**(业绩预告事件):费率能过,但须先证明公告日 PIT 轴对冻结版指增有独立增量,否则算墓地重提;需自建巨潮 PIT 采集(与转债事件采集同构)。
- **ToM 的 A股腿**:美股腿已死;A股腿等免费数据拉长+机制证据再议。
- **Listing 负漂移**(新上线 perp 三个月 -23%):值一个预注册假设,3× 滑点 haircut,不显著即归档。
- **税费运维项**(红利税除权日避让等):有界的一次性算术,等 QMT 真金落地时执行,不烧预注册名额。

## 四、判死的(20 个,墓碑一句话)

美股隔夜漂移(NY Fed 2026 亲手宣判:2021-25 ≈0,做该策略的 ETF 已清盘)、美股
PEAD(成本吃 70-100% 且大盘股已消失)、52 周高点(与已判死截面动量同源,Levine-
Pedersen 证明是等价线性滤波)、美股指数效应(纳入效应 <1%)、ST 摘帽(政策定向
爆破)、新股/次新/大宗折价(散户无门)、商品季节性(2000 年后 OOS 消失)、商品
期限结构择时(撞我们自己 E52 的实测:前后半 0.82/-0.40)、dual momentum(发表后
跑输买入持有)、残差动量(文献只有股票截面版=墓地边缘)、波动率目标化新变体
(E26 墓地正面撞击,我们的账本已饱和持有该机制)、稳定币供应信号(被一手文献
正面否定)、时段季节性(费率算术处死)、return stacking(小资金下价值≈0)等。

**注意这里的自我修正**:工作流的调查层曾把"期限结构择时""波动率管理敞口"标为
viable,打分层用我们自己的 E52/E26 实测记录把它们否了——**上一层的乐观被下一层
的墓地记录纠正**,这正是流程该有的样子。
